# RFC 9000 §10.3 无状态重置令牌保密性与唯一性审计

## 1. 约束条款（原文出处）

RFC 9000 §10.3.1：无状态重置令牌由端点为每个它发出的连接 ID 生成（随机或 `HMAC(static key, connection ID)` 派生）；令牌**必须保密**，任何能够预测令牌的对手都能重置对应连接。

RFC 9000 §10.3.2（原文要点）：
> 两个连接 ID **不得**分配相同的无状态重置令牌（同一端点内令牌碰撞必须避免——错误匹配会掐断无辜连接）。

RFC 9000 §10.3.3：接收方在无法关联到任何活动连接的短头包上匹配到重置令牌时，**必须**进入 draining 状态并丢弃连接状态。

RFC 9000 §21.11：无状态重置制造了一类"类 TCP reset 注入"的 DoS——实现必须避免构造出 **Stateless Reset Oracle**（攻击者可借第三者服务器探测令牌的状态），共享同一重置密钥的多后端部署 + 非确定性路由是该攻击的必要条件。

核心模式一句话：**16 字节的令牌是连接的生杀大权——它不需要攻破加密，只需要被推导、被泄露或被复用，任何能把它放到 UDP 包末尾的人就能无声掐断一条加密连接。**

## 2. 违规判定条件

| 编号 | 探测 | 判定 |
|---|---|---|
| SR-1 | 收集同一端点轮换前后的多个连接 ID，分析令牌与 CID 之间是否存在可推导关系（如令牌 = F(CID) 且 F 可从公开头字段重建） | 存在可推导关系 → 违规（CVE-2026-50009 Netty 实证：HMAC 构造未做域分离，轮换后的 CID 字节泄露旧令牌） |
| SR-2 | 验证令牌生成是否做密钥域分离：CID 生成与令牌生成是否共用同一 HMAC 上下文/输入 | 未域分离 → 高风险 |
| SR-3 | 探测令牌碰撞策略：同一连接内主动触发多次 CID 轮换，统计令牌是否唯一 | 出现重复令牌 → 违反 §10.3.2 |
| SR-4 | 向活动连接发送伪造 Stateless Reset 包（正确 16 字节尾 + 不可关联短头），观察是否被接受 | 被接受即协议行为合规，但确认对端接受路径无源地址校验属记录项；发送路径上是否限制速率/前缀为审计点 |
| SR-5 | 部署面探测：多后端共享重置密钥 + 路由非确定性时，通过 A 后端获取的令牌能否在 B 后端生效 | 生效 → Stateless Reset Oracle 成立 |
| SR-6 | 对已销毁/刚关闭的连接发送携带其旧令牌的无状态重置包，观察实现（xquic 实证模式） | NULL 指针解引用/崩溃 → 违规 |

判定方法：长连接抓 CID 轮换序列 + 令牌观测（需 on-path 或同机测试）；aioquic 构造伪造重置包；多后端路由测试。

## 3. 攻击面猜想

- **定向连接掐断（DoS）**：SR-1/SR-5 ——on-path 或 oracle 场景下无认证掐断任意连接，对长连接服务（实时音视频、金融推送）杀伤力大
- **重置反射**：攻击者借第三方服务器的重置响应做反射/探测
- **无认证崩溃**：SR-6 ——令牌匹配路径处于连接查找失败分支，与已销毁连接状态交互是 fuzz 高频崩溃区

## 4. 关联历史 CVE

| CVE / 证据 | 实现 | 根因 |
|---|---|---|
| **CVE-2026-50009**（CVSS 4.8，CWE-200/CWE-330，GHSA-cq4q-cv5g-r8q5） | Netty < 4.2.15.Final | 默认 HMAC 生成器对 CID 与重置令牌未做密码学域分离：源 CID 轮换后，新 CID 的明文字节泄露旧 CID 的重置令牌，on-path 攻击者可伪造 Stateless Reset 掐断连接。修复：域分离 KDF |
| QUIC-FUZZ 实测 | xquic | 对已销毁连接收到 Stateless Reset 时访问已释放的网络路径指针 → NULL 解引用 DoS（SR-6 实证） |
| QUIC-FUZZ 实测 | Quicly | 断言失败崩溃（CVE-2024-45396），同类无认证路径模式 |
| Stateless Reset Oracle（RFC 9000 §21.11） | 部署层 | 非 IETF 文献（arXiv:2306.17568）系统核查过各实现对 §21.11 的遵循情况——该条款的 MUST 分布零散，属系统性盲区 |

## 5. 差分验证方法

对照组：quic-go ≥ 0.60（令牌随机生成 + 独立密钥）、Netty ≥ 4.2.15.Final、msquic。
对比字段：SR-1 可推导性、SR-2 域分离、SR-3 碰撞率、SR-6 销毁连接容忍度、SR-5 部署面。
误报排除：实现使用随机令牌且每 CID 独立生成属合规；`HMAC(static, CID)` 构造但做了域分离且密钥不可推导亦合规；只标记"可推导""碰撞""共享密钥 + 非确定性路由"。

## 6. 对接的攻击 Skill

- 技能层（怎么打）：`slowhttptest-dos`（长连接定向掐断验证）、`fuzzowski-network-fuzz`（令牌匹配路径 fuzz）
- 工具层（用什么打）：aioquic（伪造重置包）、on-path 抓包分析脚本、多后端路由探针
