## Installation

```bash
git clone https://github.com/altf4/untwister && cd untwister && make
```

## Parameter Quick Reference

| Parameter / Command | Description |
| --- | --- |
| `./untwister -r mt19937 < randoms.txt` | PRNG seed recovery |
| `-r glibc` | glibc rand |
| `-u 1000` | Upper limit |
